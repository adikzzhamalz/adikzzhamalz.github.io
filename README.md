# Personal Branding Website
**Muhammad Rizky Pratama**

## Struktur File
```
PBRANDING/
├── index.html        → Homepage
├── about.html        → About Me
├── skills.html       → Skills
├── portfolio.html    → Portfolio
├── cv.html           → Curriculum Vitae
├── css/
│   ├── style.css     → Global styles (navbar, footer, shared)
│   ├── home.css      → Homepage styles
│   ├── about.css     → About page styles
│   ├── skills.css    → Skills page styles
│   ├── portfolio.css → Portfolio page styles
│   └── cv.css        → CV page styles
├── js/
│   ├── main.js       → Shared JS (navbar, scroll, animations)
│   ├── home.js       → Typewriter, particles, counter
│   ├── skills.js     → Skill bar animations
│   └── portfolio.js  → Filter functionality
└── img/              → Taruh foto di sini
    ├── profile.jpg   → Foto profil utama
    ├── family.jpg    → Foto keluarga
    ├── hobby-reading.jpg
    ├── hobby-gaming.jpg
    ├── hobby-fishing.jpg
    ├── hobby-sport.jpg
    ├── porto-1.jpg ~ porto-6.jpg → Screenshot portfolio
```

## Cara Pakai
1. Buka `index.html` di browser
2. Ganti foto di folder `img/` sesuai nama file di atas
3. Edit teks di masing-masing HTML sesuai kebutuhan
4. Untuk cetak CV: buka `cv.html` → klik tombol "Print / Download PDF"
